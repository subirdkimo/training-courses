## §2 端到端架構
【銜接】「看拼起來長什麼樣。」
【講解要點】（10 分鐘）帶圖：请求→API 層→分流（RAG/Tool/Agent）→生成→回應+埋點。強調 routing=整合核心：90% 簡單走輕路徑、10% 複雜才動用 Agent。
【demo 提示】貼架構圖，指每條路徑。
【Q&A】問「為什麼不能都用 Agent？」→ 答：貴/慢/失控；分流是成本延遲的解。

## §3 API 層
【銜接】「把本機 script 變成『可被呼叫的 API』。」
【講解要點】（8 分鐘）輸入驗證（Pydantic）/auth/錯誤映射（不洩密）/降級。帶 FastAPI /ask 示例。
【demo 提示】live 起一個 /ask endpoint，curl 打一個請求。
【Q&A】問「為什麼要 auth 限流？」→ 答：獨立計費+防刷+獨立 revoke。

## §4 key 管理+降級
【銜接】「產品級＝任一零件壞了整體還給得過一個可接受結果。」
【講解要點】（10 分鐘）key 集中/獨立 quota/可單獨 revoke；降級四條（failover/切便宜模型/退回無資料/部分交付）。
【demo 提示】示範一個 501 降級到便宜模型的回應。
【Q&A】問「LLM API 掛了怎麼辦？」→ 答：備用 provider 接手；仍不行回『系統繁忙』。

## §5 日誌與可觀測性
【銜接】「沒有日誌，線上問題只能猜。」

【Q&A】問「日誌最重要？」→ 答：demo 和產品最隱形但關鍵的差距。
